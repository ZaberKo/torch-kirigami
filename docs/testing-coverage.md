## 完成边界

表内适用契约有可执行断言；有限坐标穷举只证明选定小域。更大网络、所有轴/尺寸/dtype/stride/训练态的笛卡尔积、所有 PyTorch 版本和设备并未穷举。固定组合选取互相影响的因素，后续缺陷仍需补最小回归。CPU 跳过 CUDA 不能替代 GPU 验收，实际环境结果见 [测试记录](testing.md)。
